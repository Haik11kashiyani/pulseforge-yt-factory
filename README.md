# PulseForge Studio — Kotlin Android App & Encrypted GitHub YouTube Factory

## How to Get Your Installable `.apk` on Your Phone (Zero Laptop Needed)
1. Upload this repository to your GitHub account.
2. Open the **Actions** tab on GitHub from your phone browser and run **1. Build Installable Kotlin Android APK**.
3. In ~2 minutes, scroll down to **Artifacts** on that workflow run and tap **`PulseForge-Studio-Android-APK`** to download and install the native Kotlin app on your Android phone!
